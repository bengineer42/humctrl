# The humidity rig

A chamber held at a target relative humidity by blending the output of two
pumps — one wet, one dry — under closed-loop control. The controller is
flyball; this book covers only what is specific to this rig: the hardware,
the drivers, and how to operate it.

| --- | --- |
| build or repair the board | **Hardware** |

in the flyball book, not here.
